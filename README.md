# PLP Python Week 4 Assignment

- **welcome.py**: Contains a reusable greeting function to welcome individuals by name.
- **toolbox.py**: Contains a utility toolkit with functions for doubling numbers, checking pass status, and customized greetings with default arguments.

### Reflection
The hardest function to write was `greet` with the optional parameter because I had to carefully combine string concatenation, commas, and exclamation marks while making sure the default argument syntax handled missing values correctly.
